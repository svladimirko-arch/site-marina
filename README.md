# Сайт салона-ателье «Марина»

Откройте `index.html` двойным кликом — сайт работает прямо из папки.
Для публикации загрузите всё содержимое этой папки на хостинг (index.html должен лежать в корне).

## Что поменять под себя
- `config.js` — название, город, адрес, телефон, ВК, часы работы, координаты карты.
  Данные уже заполнены с карточки Яндекса: Домодедово, ул. Кирова, 7, корп. 1, +7 965 230 15 57.
- `images/` — логотип и фото (имена файлов не менять):
  `logo.png`, `favicon.png`, `hero-poster.jpg` (главный блок, 2:3),
  `portfolio-1.jpg … portfolio-3.jpg`.
  Необязательно: `hero-video.mp4` — вертикальное видео в главный блок.
- Цены и тексты — прямо в `index.html` (цены сейчас «0 000 ₽»).
